- Campos eliminados: nombre, email, teléfono, dirección.
- Fechas transformadas a: año_bucket / días desde evento maskeado.
- Hashing: campo pseudónimo ha sido hasheado con salt desconocido públicamente.
- Texto libre: NO incluido / incluido tras revisión y anonimización manual.
